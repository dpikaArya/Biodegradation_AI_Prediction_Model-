# Biodegradation_AI_Prediction_Model-# Biodegradation Prediction Model

A reproducible machine learning workflow for predicting biodegradation percentage from experimental data using Gradient Boosting regression.

## **Overview**
This project provides a complete, reproducible workflow for:
1. Processing raw Excel data from biodegradation experiments
2. Preparing features and target for machine learning
3. Training and evaluating multiple regression models (Linear Regression, Random Forest, Gradient Boosting)
4. Generating publication-quality visualizations
5. Exporting results to Excel and saving the trained model

The **best performing model** is **Gradient Boosting** with:
- Test R²: 0.8005
- Test RMSE: 16.75
- Test MAE: 12.59

[REPRODUCIBILITY.md](https://github.com/user-attachments/files/28230616/REPRODUCIBILITY.md)
## **Data**
The raw data is stored in `Biodegradation_ML_Ready.xlsx` and contains experimental data for:
- **Pollutants**: Resorcinol and p-Cresol
- **Initial Concentrations**: 10, 30, 50, 70, 90, 100, 300, 500, 700, 900, 1300 mg/L
- **Time Points**: 0 to 185 hours
- **Target Variable**: `Degradation_%` (percentage of pollutant degraded)


## **Workflow**
The workflow is implemented in `biodegradation_workflow.py` and follows these steps:

1. **Data Processing**: Extract and clean time series data from the Excel file
2. **Feature Preparation**: Encode categorical variables, split into train/test sets
3. **Model Training**: Train Linear Regression, Random Forest, and Gradient Boosting models
4. **Evaluation**: Calculate R², RMSE, and MAE for all models
5. **Visualization**: Generate publication-quality plots (predicted vs actual, residuals, feature importance, partial dependence)
6. **Export**: Save model, metrics, predictions, and plots[biodegradation_model_results.xlsx](https://github.com/user-attachments/files/28230626/biodegradation_model_results.xlsx)

## **Usage**
### **Run the Full Workflow**
```bash
python biodegradation_workflow.py
```

This will:
1. Process `Biodegradation_ML_Ready.xlsx`
2. Train and evaluate models
3. Generate all plots and export results to the `results/` directory

### **Load and Use the Trained Model**
```python
import pickle
import numpy as np

# Load the model
with open('results/biodegradation_prediction_model.pkl', 'rb') as f:
    model = pickle.load(f)

# Example prediction
# Features: [Initial_Conc_mg_L, Time_h, Pollutant_Type_Resorcinol]
# Pollutant_Type_Resorcinol: 1 = Resorcinol, 0 = p-Cresol
sample = np.array([[500.0, 50.0, 0.0]])  # 500 mg/L, 50 hours, p-Cresol
predicted_degradation = model.predict(sample)
print(f"Predicted Degradation: {predicted_degradation[0]:.2f}%")
```


## **Results**
All results are saved in the `results/` directory:

### **Excel File: `biodegradation_model_results.xlsx`**
Contains 3 sheets:
1. **`Model_Metrics`**: Performance metrics for all models (R², RMSE, MAE)
2. **`Feature_Importance`**: Built-in and permutation importance for all features
3. **`Test_Set_Predictions`**: Detailed predictions for the test set

### **Visualizations (Publication Quality, 300 DPI)**
1. `predicted_vs_actual_test.png`: Predicted vs Actual (Test Set)
2. `predicted_vs_actual_train.png`: Predicted vs Actual (Training Set)
3. `residual_plot_test.png`: Residuals vs Predicted Values
4. `residual_histogram_test.png`: Histogram of Residuals
5. `feature_importance.png`: Feature Importance Plot
6. `partial_dependence_time.png`: Partial Dependence Plot for Time
7. `partial_dependence_initial_conc.png`: Partial Dependence Plot for Initial Concentration

### **Model and Data**
- `biodegradation_prediction_model.pkl`: Trained Gradient Boosting model
- `ml_data.npz`: Processed ML data (features, target, splits)
- `degradation_data_clean.csv`: Clean raw data
